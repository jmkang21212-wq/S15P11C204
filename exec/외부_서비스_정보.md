## 1. 네이버 로그인 (소셜 인증)

LAIVE의 **유일한 소셜 로그인 수단**이다. 스트리머용 Electron 앱에서만 사용한다
(일반 사용자·광고주가 보는 웹 공개 화면은 비로그인).

| | |
|---|---|
| 가입·발급 | <https://developers.naver.com/apps> → 애플리케이션 등록 |
| 사용 API | **네이버 아이디로 로그인** |
| 필요한 제공 정보 | 회원 이름 · 이메일 주소 · 별명 (코드가 `id`/`email`/`nickname`/`name`을 읽는다 — `NaverProfile.java`) |
| 서비스 환경 | PC 웹 |

### 콘솔에 등록할 Callback URL

등록한 값과 요청 값이 **완전히 일치**해야 한다. 두 개 다 등록해 둔다.

```
http://localhost:8080/api/v1/auth/oauth/naver/callback              (로컬)
https://i15c204.p.ssafy.io/api/v1/auth/oauth/naver/callback         (배포)
```

### 환경변수 — `BackEnd/spring/laive/.env`

| 변수 | 값 |
|---|---|
| `NAVER_CLIENT_ID` | 개발자센터 발급 |
| `NAVER_CLIENT_SECRET` | 개발자센터 발급 |
| `NAVER_REDIRECT_URI` | 위 Callback URL 중 환경에 맞는 값 |

### 코드가 호출하는 엔드포인트 (`application.yaml` `laive.auth.naver`)

```
authorize     https://nid.naver.com/oauth2.0/authorize
token         https://nid.naver.com/oauth2.0/token
user-info     https://openapi.naver.com/v1/nid/me
```

### 주의

- 로그인 후 돌아갈 주소는 `OAUTH_ALLOWED_RETURN_URIS` 화이트리스트에 있어야 한다.
  이 값은 **CORS 허용 오리진의 원천이기도 해서**, 빠지면 공개 조회 API까지 403이 된다
  (설치 앱은 `laive://app/oauth/callback`이 반드시 필요 — `DEPLOY.md` §2-1).
- 콘솔에 Callback URL을 등록하지 않으면 코드가 맞아도 네이버가 거부한다. 반영에 시간이 걸릴 수 있다.
- 로컬 개발은 `DEV_LOGIN_ENABLED=true`로 네이버 없이 로그인할 수 있다. **배포에서는 절대 켜지 않는다.**

## 2. 치지직 (CHZZK) Open API — 방송 플랫폼 연동

스트리머 계정 연동, 방송 제목·카테고리 설정, **실시간 채팅 수집**에 쓴다.

| | |
|---|---|
| 가입·발급 | 치지직 개발자센터 <https://developers.chzzk.naver.com> → 애플리케이션 등록 |
| 발급값 | Client ID / Client Secret |
| 인증 방식 | OAuth 2.0 (스트리머 본인이 앱에서 "연동" 버튼으로 승인) |

### 콘솔에 등록할 로그인 리디렉션 URL

```
http://localhost:8080/api/v1/platform-accounts/chzzk/callback        (로컬)
https://i15c204.p.ssafy.io/api/v1/platform-accounts/chzzk/callback   (배포)
```

### 환경변수 — `BackEnd/spring/laive/.env`

| 변수 | 설명 |
|---|---|
| `CHZZK_CLIENT_ID` / `CHZZK_CLIENT_SECRET` | 개발자센터 발급 |
| `CHZZK_REDIRECT_URI` | 위 리디렉션 URL |
| `PLATFORM_TOKEN_KEY` | 발급받은 **플랫폼 토큰을 DB에 암호화 저장**하는 키 (NFR-S-03). Base64 인코딩 32바이트 — `openssl rand -base64 32` |

### 사용하는 엔드포인트

| 구분 | URL | 쓰는 곳 |
|---|---|---|
| 인증 화면 | `https://chzzk.naver.com/account-interlock` | Spring (`ChzzkOAuthClient`) |
| 토큰 발급/폐기 | `https://openapi.chzzk.naver.com/auth/v1/token`, `.../token/revoke` | Spring |
| 내 정보 | `https://openapi.chzzk.naver.com/open/v1/users/me` | Spring |
| 방송 설정 | `https://openapi.chzzk.naver.com/open/v1/lives/setting` | Spring |
| 채팅 세션 | `.../open/v1/sessions/auth` → socket.io → `.../open/v1/sessions/events/subscribe/chat` | AI 수집기(8002) |
| 동시 시청자 수 | `https://api.chzzk.naver.com/polling/v2/channels/{channelId}/live-status` | AI 수집기(8002) |

### 주의

- **채팅 수집은 별도 키가 없다.** OAuth로 받은 스트리머 액세스 토큰을 그대로 Bearer로 쓴다
  (`AI/chat-collector/chatcollector/chzzk.py`).

## 3. YouTube Data API v3 / Live Streaming API (선택)

유튜브 방송 연동·채팅 수집용 어댑터. **세 변수를 모두 채웠을 때만 활성화**되고, 비워두면 치지직만 동작한다.

| | |
|---|---|
| 가입·발급 | Google Cloud Console <https://console.cloud.google.com> → 프로젝트 생성 |
| 활성화할 API | **YouTube Data API v3** (Live Streaming API 포함) |
| 만들 것 | OAuth 2.0 클라이언트 ID (웹 애플리케이션) + OAuth 동의 화면 |
| 요청 scope | `https://www.googleapis.com/auth/youtube.force-ssl` (`YouTubeOAuthClient.java`) |

### 승인된 리디렉션 URI

```
http://localhost:8080/api/v1/platform-accounts/youtube/callback
https://i15c204.p.ssafy.io/api/v1/platform-accounts/youtube/callback
```

### 환경변수 — `BackEnd/spring/laive/.env`

| 변수 | 설명 |
|---|---|
| `YOUTUBE_CLIENT_ID` / `YOUTUBE_CLIENT_SECRET` | Google Cloud OAuth 클라이언트 |
| `YOUTUBE_REDIRECT_URI` | 위 URI 중 하나와 **정확히 일치** |
| `YOUTUBE_BROADCAST_PRIVACY` | LAIVE가 만드는 방송의 공개 범위. 기본 `unlisted` — 설정을 빠뜨려도 전체 공개되지 않게 한 기본값이다 |

### 주의

- OAuth 동의 화면이 **테스트 모드**면 등록한 테스트 사용자 계정만 연동된다. 시연 계정을 미리 등록해 둘 것.
- Data API는 **일일 쿼터(기본 10,000 units)** 가 있다. 수집기는 `liveChat/messages`를 폴링하므로
  동시 방송이 늘면 쿼터가 먼저 마른다.
- 리프레시 토큰을 받으려고 `access_type=offline` + `prompt=consent`로 요청한다.

## 4. Groq — 음성 인식 (Whisper)

스트리머 발화를 실시간 전사해 위험 발언을 감지한다(AI 8000).

| | |
|---|---|
| 가입·발급 | <https://console.groq.com> → 무료 가입 → API Keys |
| 발급값 | `gsk_`로 시작하는 API Key |
| 모델 | `whisper-large-v3` (`STT_MODEL`, `whisper-large-v3-turbo`로 교체 가능) |
| 넣는 곳 | `AI/.env` → `GROQ_API_KEY` |

### 주의

- **키가 없으면 8000번 서버가 기동 자체를 못 한다** (`app/config.py`가 `RuntimeError`를 던진다).
- **무료 티어는 하루 약 2,000건.** 발화 1건 = 요청 1건이라 활발한 방송 기준 약 2시간 분량이며,
  동시 접속자가 늘면 그만큼 빨리 소진된다. 시연 전날 소진하지 않도록 주의.
- CI(Jenkins)에서는 실제 호출이 없어 `GROQ_API_KEY='ci-test-placeholder'`로 채워 테스트만 돌린다.

## 5. SSAFY GMS — LLM · 임베딩 (OpenAI 호환 프록시)

SSAFY가 제공하는 OpenAI 호환 프록시다. **OpenAI에 직접 가입하지 않는다** — base URL만 바꿔 끼운다.

```
https://gms.ssafy.io/gmsapi/api.openai.com/v1
```

| 항목 | 값 |
|---|---|
| 가입·발급 | SSAFY GMS (교육생 계정으로 키 발급) |
| 발급값 | GMS Key 1개 — AI·백엔드가 **같은 키를 공유**한다 |

### 넣는 곳

| 변수 | 파일 | 쓰는 곳 |
|---|---|---|
| `GMS_KEY` | `AI/.env` | 위험 발언 LLM 판정(8000), 여론 요약·질문 임베딩(8001) |
| `REPORT_AI_API_KEY` | `BackEnd/spring/laive/.env` | 세션 리포트·성장 액션·로드맵 (Spring AI) |
| `REPORT_AI_BASE_URL` | 〃 | 위 base URL을 그대로 넣는다 (기본값은 `api.openai.com`이라 **반드시 덮어써야 한다**) |
| `REPORT_AI_MODEL_ENABLED` | 〃 | `openai` — Spring AI ChatModel 자동 구성 지정 |

### 사용 모델

| 모델 | 용도 | 정의 위치 |
|---|---|---|
| `gpt-5-mini` | 위험 발언 문맥 판정 · 약속 추출 | `AI/app/config.py` |
| `gpt-5-nano` | 채팅 여론 요약 (mini보다 사용량 제한이 여유로워 선택) | `AI/chat-ai/chatai/config.py` |
| `text-embedding-3-large` | 반복 질문 클러스터링 (3-small은 실측에서 같은 질문을 못 묶어 쓸 수 없다) | 〃 |
| `gpt-4.1-mini` | 세션 리포트·성장 AI | `BackEnd/.../application.yaml` |

### 주의

- **`gpt-5` 계열은 `temperature` 기본값 1만 허용한다.** 모델을 그쪽으로 바꾸면
  `REPORT_AI_TEMPERATURE=1`로 같이 올려야 400(`unsupported_value`)이 안 난다.
- 키가 없어도 서버는 뜬다. 대신 `/summary`가 **503**, 리포트 AI 작업은 재시도 후 **PARTIAL**로 끝난다.
- 리포트·성장 AI는 기본이 꺼져 있다 — `REPORT_AI_ENABLED` / `GROWTH_AI_ENABLED` / `GROWTH_ROADMAP_AI_ENABLED`.
- GMS는 **사용량 제한이 있는 공용 자원**이다. 요약은 60초 쿨다운·최소 채팅 30건,
  FAQ 판정은 배치당 50건 상한으로 호출을 묶어 두었다. 이 가드를 풀면 비용이 샌다.

## 6. Google Drive — 감정 분류 모델 배포

채팅 감정 분류 ONNX 모델(fp32 511MB / int8 129MB)은 용량 때문에 git에 넣지 않고 **팀 Google Drive**에 둔다.

| | |
|---|---|
| 위치 | <https://drive.google.com/drive/folders/1aEUXDciPMKllT-FvAAUgCy-hwNRdG5qU> |
| 공유 설정 | **"링크가 있는 모든 사용자(뷰어)"** — 아니면 다운로드가 HTML 안내 페이지로 바뀐다 |
| 받는 방법 | `python AI/chat-ai/fetch_model.py` (파일 ID·기대 크기가 코드에 박혀 있다) |
| Docker | 이미지 빌드 시 자동 다운로드 — 첫 실행 5~10분. 미리 굽기: `docker build --build-arg BAKE_MODEL=true -t laive-ai:latest AI` |

모델을 갱신할 때는 같은 폴더에 새 파일을 올리고 `fetch_model.py`의 파일 ID·크기를 함께 고친다.

## 7. OBS Studio + obs-websocket — 로컬 외부 소프트웨어

클라우드 서비스는 아니지만 **스트리머 PC에 반드시 설치돼 있어야 하는 외부 프로그램**이다.
LAIVE는 OBS의 녹화본을 잘라 하이라이트 클립을 만든다(서버는 ffmpeg를 돌리지 않는다).

| | |
|---|---|
| 필요 버전 | OBS Studio 28 이상 (obs-websocket 5.x 내장) |
| 연결 주소 | `ws://127.0.0.1:4455` (앱 화면에서 변경 가능) |
| 인증 | OBS의 `도구 → obs-websocket 설정`에서 켜고 비밀번호 확인 → LAIVE 앱에 입력 |
| 클라이언트 | `obs-websocket-js` 5.x (Electron main 프로세스가 소켓을 소유) |
| 필요한 권한 | 녹화 시작/중지, 녹화 경로 조회 |
