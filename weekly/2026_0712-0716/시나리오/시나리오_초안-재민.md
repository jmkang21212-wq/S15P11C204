# 시나리오 초안-재민

### 1. 방송 전 — 콘텐츠 추천

- "오늘 방송 뭐 하지?" → AI 매니저가 콘텐츠 추천
- 근거: 최근 트렌드 + 개인 일정 → **"오늘 SSAFY 발표일이네요, 프로젝트 발표 방송 어떠세요?"**

### 2. 방송 설정 & 공지

- LLM이 방송 제목 등 메타데이터 추천
- MM(Mattermost) 연동 → 공지방에 방송 링크 자동 발행
- 방송 시작

### 3. 오프닝 — 인사 & 기획 설명

- 프로젝트 소개: 니즈 / 제공 가치 / 차별성
- 시연 시작 선언
- 방송 전 기능(일정 관리·콘텐츠 기획) 간단 설명

### 4. 방송 중 — 실시간 매니징

1. **호응 유도**: "열혈 시청자 1분께 기프티콘" 약속 → 약속 추적 기능 설명
2. **매니저 브리핑 패널**: 시청자 이탈 가속·채팅 침체·분위기 급상승을 룰 기반 감지 → LLM이 페르소나 말투로 코칭 ("최근 10분 시청자 -15%, 콘텐츠 환기 타이밍입니다") — 2층 구조
3. **하이라이트 구간 자동 측정** + 수동 추가
4. **실시간 발언 모니터링** (리스크 감지)
5. 방송 종료

### 5. 방송 후 — 오늘의 방송 리포트

1. 하이라이트 마커 · 채팅 감정 히트맵 · 약속 추적 결과
2. 기프티콘 당첨자 발표
3. 하이라이트 구간 → 클립/쇼츠 초안 생성
4. 다음 방송 콘텐츠 제안 (오늘 못 한 콘텐츠, 근거 기반)
5. 방송 내용 기반 스트리머 페르소나 생성
6. 다른 스트리머와의 궁합
7. 광고 매칭
