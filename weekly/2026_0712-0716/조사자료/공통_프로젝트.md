# 공통 프로젝트

## 1. 보드게임

- 방 생성 및 초대
- 2~4인 WebRTC 음성·화상
- 서버 기준의 게임 상태 동기화
- 룰북 RAG 기반 AI 질의응답
- 게임 종료 후 핵심 장면 3개 분석 → 승률이 퐉 올랐을 때 top 3
- 특정 수로 돌아가 AI와 다시 보드게임을 진행할 수 있는 리플레이 기능
- 초보자 전용 AI 힌트 제공(놓친 요소, 고려할 선택지 등)
- 초보자를 위한 인터랙티브 튜토리얼
- 팀 전용 음성 채널
- 자원 관리·템포·규칙 이해도·상대 견제 정도 등의 플레이 스타일 분석
- 플레이 중간 저장 / 이어하기
- 게임 종료 후 MVP 투표
- AI 플레이어
- 발화 감지 기반 UI 하이라이트 (누가 말하는 중인지)
- DataChannel 기반 실시간 커서/제스처 공유
- Self-play 강화학습 봇 (Python 서비스 분리)
- **AI 전적 카드** — 게임 종료 시 MVP 투표(보유)와 묶어 "오늘의 배신자", "최다 견제 유발" 같은 공유용 밈 카드 자동 생성 — 상호평가에서 "멋있어 보이는" 저비용 고효과
- **음성 착수 + 보드 낭독 모드** — "D3에 둘게"로 플레이하고, 보드 상태를 음성으로 낭독. RTC 오디오(보유)의 활용 심화이자, 시각·운동 접근성으로 상담 안에 있던 사회공헌 축
- **탈주자 대타 AI** — 이탈한 플레이어의 스타일 프로파일(보유 데이터)로 AI가 그 사람처럼 이어서 둠. 온라인 게임의 고질병을 우리 데이터로 푸는, 기술적으로 가장 섹시한 기능 중 하나
- **대화형 복기 코치** — 리플레이(보유) 위에서 음성으로 "여기서 왜 이게 나빠?"를 묻고, AI가 엔진 평가치+자연어로 답하며, 대안 수를 직접 두면 그 분기를 이어서 시뮬레이션. "핵심 장면 3개 분석"의 정적 리포트를 대화로 승격 — 바둑 복기 문화의 이식이자 에이전틱 AI 요건의 정답 지점

### Part 1. AI 매니저 기능 — 연예인 매니저 역할 매핑

**① 일정 관리 → 방송 스케줄 매니징**

- 시청자 접속 패턴 분석 기반 최적 방송 시간대 추천
- 방송 캘린더 관리 + 방송/휴방 공지 자동 발행 (디스코드·X 연동)
    - 공지 다른 플랫폼에 쏠수 있는 방법 찾아보기(API)

**② 콘텐츠 기획 → 데이터 기반 콘텐츠 코칭**

- 트렌드 분석 기반 콘텐츠 아이템 추천 (급상승 게임·카테고리)
    - 상위 규모·카테고리 스트리머 벤치마킹 아이디어
- 지난 방송 분석: 리
    - 다음 방송 제안 : 근거 데이터를 링크로 연결한 제안("공포게임 구간 하이라이트 4건 발생 → 근거 클립 보기")을 제공하고, 스트리머의 채택/거절과 실제 성과가 다시 프로필에 축적되는 피드백 루프
- 채팅 급증 구간 자동 감지 → 하이라이트 클립/쇼츠 초안 생성
- 방송 제목·썸네일 시안 제안 및 회차별 성과 비교

**③ 팬덤 관리 → 시청자 커뮤니티 매니징**

- 실시간 채팅 요약: 여론 흐름, 반복 질문을 방송 중 스트리머에게 브리핑
- AI 모더레이션: 악성 채팅·도배 감지 및 자동 조치 → 한명이 악플 담당
- 열성 시청자(후원 상위, 채팅 활발) 식별 → 식별해서 나중에 스트리머가 우선순위 부여하는 정도?
    - **시참 대기열 관리** : "!시참" 명령어 입력 순서대로 대기열을 관리하고 오버레이에 대기 목록을 표시하며 추첨 기능을 제공한다. 게임 방송인의 실제 니즈이자 시연 시 심사위원 참여 요소.
- 방송 종료 후 "오늘의 방송 리포트" 자동 생성
    - **하이라이트 마커, 채팅 감정 히트맵**
- **약속 추적기** : "다음에 그 게임 할게요" 같은 방송 중 약속 발언을 채팅 반응에서 감지하거나 스트리머가 태그하면 약속 목록으로 관리하고, 다음 방송 전 브리핑에서 미이행 약속을 리마인드한다. 시청자와의 신뢰를 관리하는 매니저다운 기능.
- **매니저 브리핑 패널** : 주기적 코멘트가 아닌 이벤트 구동형 매니저. 시청자 이탈 가속, 채팅 침체, 분위기 급상승 등 상태 변화를 룰 기반으로 감지하고 LLM이 페르소나 말투로 코칭 메시지를 생성하는 2층 구조("최근 10분 시청자 -15%, 콘텐츠 환기 타이밍입니다"). 매니저 캐릭터가 말풍선으로 브리핑하는 UI로 엔터테인먼트 감성을 살린다.

**④ 이미지·위기 관리 → 리스크 매니징**

- 방송 중 STT 기반 실시간 발언 모니터링 → 논란 소지 발언 즉시 경고
    - 소리를 → 로컬모델로 텍스트로 바꾸고 → LLM으로
    - 과한 욕설 / 성적 발언 / 정치적 발언 등 → soop 등 자체 솔루션 있을 듯

**⑤ 커리어 관리 → 성장 전략 코칭**

- 주간·월간 성장 리포트 (팔로워, 평균 동시 시청자, 총 시청 시간)
- 상위 규모·카테고리 스트리머 벤치마킹 아이디어
- 목표 설정 및 달성 로드맵 관리

### Part 2. 네트워킹·협업 플랫폼 기능 → 차별화 기능

**① 스트리머 프로필 (포트폴리오)**

- 방송 통계 자동 연동 포트폴리오: 평균 시청자, 주력 콘텐츠, 시청자 데모그래픽
- 협업 이력과 상호 리뷰 (신뢰도 지표)
- 기업용 미디어 킷 자동 생성 (주요 콘텐츠, 시청자 특성, 대표 콘텐츠 등…)

**② 합방(콜라보) 매칭 — 핵심 기능 후보**

- AI 궁합 매칭: 카테고리, 시청자층 겹침 정도, 방송 시간대, 채널 규모 기반
- 합방 제안 → 수락 → 일정 조율 플로우
- 사전 미팅 및 합방 진행용 실시간 화상·음성 룸(버튜버 합방)
- 합방 후 상호 성과 리포트: 서로에게서 유입된 신규 시청자 분석
- 친구 채널(디코 벤치마킹) 친구들끼리 쓰는 방. 단, 수다 떠는 방이 아니라 **"합방을 만드는 방"**
    - **친구 상태판**: 누가 지금 방송 중인지, 무슨 게임 하는지, 합방 가능한지 한눈에 보임
    - **소집 버튼**: "지금 발로란트 5인!" 누르면 방 멤버들에게 알림이 가고, 인원이 차면 합방 방이 자동으로 열림
    - **합방 방**: 클릭 한 번으로 같이 방송 시작. AI 진행자, 화면 자동 전환 같은 기능 포함
    - **방 담당 AI 매니저**: 멤버들 다 되는 시간 찾아주기, "2주째 합방 안 하셨네요" 알림, 잘 맞는 멤버 조합 추천
    - **합방 달력과 기록**: 언제 누구랑 했고 반응이 어땠는지 자동으로 쌓임
    - **채팅**: 대화용으로 간단하게만

**③ 계약·수익 관리 → 비즈니스 매니징**

- 스트리머와 기업 간의 광고 매칭 지원
- 방송 이후 스트리머에 대한 정보가 서비스에 저장
- 기업은 자신이 원하는 특성을 가진 스트리머를 해당 서비스를 통해 탐색
- 상세 보기 등으로 원하는 스트리머 탐색 후 컨택할 수 있는 별도의 연락처 혹은 경로 제공
- 실제 계약은 알아서 (여기선 X)
