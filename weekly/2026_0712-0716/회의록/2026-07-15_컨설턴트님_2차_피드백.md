## 💬 회의 내용

### 1. 팀 제시 기능안 (1인 방송인 매니저)

**방송 전**

- 최적 방송 시간대 분석 / 방송 캘린더 (방송 · 휴방 공지)
- 콘텐츠 기획 — 트렌드 기반 콘텐츠 추천
- 방송 제목 추천
- 지난 방송 분석 — 시청자 이탈 · 유입 · 채팅 활발 시간대

**방송 중**

- 실시간 채팅 요약 & 악성 채팅 감지
- 채팅 급증 구간 감지 → **쇼츠 자동 생성**
- 방송 중 실시간 이탈 감지 안내
- 열정적인 시청자 식별 (우대)
- 방송 중 논란 감지 알림 → 상시 음성 인식 필요 + 기존 플랫폼 기능과 중복 → **후순위 처리 결정**

**방송 후**

- 방송 종료 리포트 — "이런 약속을 했는데 안 지켜졌다" (약속 이행 추적)
- 주간 · 월간 성장 리포트 → 앞으로의 성장 방향성 제시

**프로필 · 네트워킹 · 광고**

- 스트리머 페르소나 → 광고주가 정보를 확인하고 컨택할 수 있게
- 스트리머 프로필 — 방송 통계 연동 / 협업 이력과 상호 리뷰
- 디스코드처럼 대화하는 기능 (스트리머 간 소통)

**멀티플랫폼**

- 멀티플랫폼 차별화 유지 — 플랫폼마다 API를 알아보기로 함

### 2. 컨설턴트 피드백

- 기획적으로 아이디어가 많음 → **화면이 너무 많아질 수 있음** → 다 구현하기엔 많은 것 같음
- 방향 제시: **① 화면을 줄이고 기술 깊이를 더하는 방향**
- 다 구현하지 않아도 좋음 — **우선순위를 정하고, 어떤 기술을 쓸지** 생각해볼 것
- **포트폴리오 활용성** 관점: 기술 욕심을 부리면 좋을 것
- **서비스명 정하기**
- 시연 관련: **"실제로 하라고 하니까 되더라"** — 실제 방송을 해보거나 쇼츠 생성을 실동작으로 시연하는 방식의 설득력 언급

### 3. 실습코치 피드백

- 공지 등 일부 기능은 **구현 시간은 걸리지만 시연 시 임팩트가 없음** → 우선순위 설정 시 "시연 임팩트 대비 공수" 기준 고려
- 프로젝트 시트 채우기

### 4. 확정 사항

- **발표 + 시연 = 15분**
