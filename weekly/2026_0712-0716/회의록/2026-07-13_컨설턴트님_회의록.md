## 💬 후보별 피드백 상세

### 1. 보드게임 (온라인 전환안)

**긍정 신호**

- AI가 게임에 개입(해설·훈수·결과 분석)하는 구도 자체는 "문제없다"
- 게임 카테고리 평가: "하면 할 게 많다 — 실시간, 동시성 제어 등. 개발할 것도 예외도 많지만 **얻는 게 되게 많다**. 나쁘지 않다"
- 과거 화제 팀 사례 공유: 테이블 키오스크로 룰 설명·턴 안내(보드게임 알바 경험 기반 — 우리와 동일한 니즈 출발), 터치 모니터 중앙 배치·턴마다 화면 회전, 프로젝터 인터랙션 등 — "구현 방법은 여러 가지, 화제 끌면 결과도 좋았다"
- 옆 반 컨설턴트가 게임 전문 — 필요 시 조언 요청 가능
- 코치: 실물 카메라 방식은 설치 편의성이 걸렸는데 온라인 전환은 "나쁘지 않다"

**숙제 (질문 형태)**

- 차별성: "온라인이면 게임 안 들고 다녀도 된다는 장점은 있지만, 유튜브 플레이 가이드를 카페에서 틀어주기도 하는데 **온라인으로 가져갔을 때 차별성이 있는가?**"
- 정체성: "온라인으로 하면 **보드게임이 아니고 그냥 게임 아닌가?**"
- 목적성: "AI가 분석·가이드·리포트를 준다면 **게임의 목적을 생각해봐라 — 잘하기 위해 계속할 것인가(실력), 여럿이 접속해 놀려는 것인가(재미)**"
- AI 실체: "**단순 해설을 만들어주는 것만으로 큰 의미가 있는지 모르겠다**" + "학습 데이터와 학습 방법이 있는지 확인해봐라 — AI가 상황을 읽고 이해해야 한다"
- 팀 내 인식: 알파고도 초기엔 기보 데이터 기반 — 우리 수준에선 데이터 확보 + AI가 인식할 형태로의 변환이 난이도 있는 과정

**팀이 제시한 카드**

- 보드게임 아레나(BGA): 다양한 게임을 엔진에 맞춰 구현해 둔 기존 플랫폼이나 **AI 기능이 전무**하고 API가 공개돼 있다고 파악 → 이를 활용해 새로운 플랫폼을 만드는 방향 (※ API 실체는 검증 필요)
- 규칙 저작권 없음(명칭·이미지만 보호) — 컨설턴트·코치도 처음 알았다는 반응, 저작권 우려 해소

### 2. 방송(스트리머) 매니저

**긍정 신호**

- "**방송 매니저를 다룬 팀은 없었다**" — 참신성은 후보 중 최고 평가

**한계 지적**

- 제어권 문제: "유튜브에서 매니저가 등장해 제어할 수 있나? 제어권이 없다" → 팀 답변: OBS 플러그인 형태로 얹는 방향

**확장 힌트**
