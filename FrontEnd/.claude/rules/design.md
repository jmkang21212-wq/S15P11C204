# LAIVE — UI 디자인 정의서

Studio Light 디자인 시스템 규칙. 컴포넌트/화면 구현 시 참고.

## 0. ⚠️ 지켜야 할 것

- **컴포넌트는 목적에 맞게 분리한다**: 화면 단위로 몰아넣지 말고, 재사용 가능한 단위(버튼, 카드, 배지 등)로 나눈다. GNB처럼 여러 화면에서 쓰이는 요소는 반드시 공용 컴포넌트로 뺀다.
- **모더레이션 관련 요소는 구현하지 않는다**: 신고 피드, 처리 큐, OBS 오버레이 경고 문구 등은 스펙에서 제외됨.
- **로딩/빈 상태/에러 상태를 모두 구현한다**: 데이터가 없거나 로딩 중이거나 실패했을 때의 UI를 빠뜨리지 않는다.
- **UI 컴포넌트는 shadcn/ui만 사용한다**: 커스텀 UI 라이브러리(MUI, Ant Design, Chakra 등)나 직접 만든 컴포넌트로 대체하지 않는다. base는 Base UI를 사용한다. 차트/KPI 카드 등 shadcn/ui가 커버하지 못하는 데이터 시각화 컴포넌트는 Tremor를 병행 허용한다.

## 1. 디자인 시스템 — Studio Light

밝은 뉴트럴 배경 위에 인디고 액센트. 방송 중 상태만 강한 레드로 구분한다.

| 토큰 | 값 | 용도 |
|---|---|---|
| Primary | `#4338ca` | 액센트, 활성 내비, 주요 버튼, 링크 |
| Primary Soft | `#eef0fb` | 활성 내비 배경, 태그 |
| Success | `#16a34a` | 완료, 증가 지표, 연결됨 |
| Danger | `#e11d48` | LIVE, 위험, 경고 배너 |
| Warning | `#d97706` | 주의, 토큰 만료 |
| Surface | `#fff` / `#f5f6f8` | 카드 / 화면 배경 |
| Text | `#191c22` / `#4a4f5a` / `#8a909c` | 본문 / 보조 / 캡션 |
| Border | `rgba(0,0,0,.08~.10)` | 구분선, 카드 테두리 |

**타이포**: 본문 Wanted Sans, 수치·ID JetBrains Mono. 화면 제목 16–18px/700, 본문 13–13.5px, 캡션 11–12px, 지표 숫자 22–34px/800. 자간 `-.01em ~ -.03em`.

**형태**: 카드 `radius 14px` + `0 10px 34px rgba(0,0,0,.09)`, 내부 요소 `9~12px`, 칩·배지 `20px`. 간격은 4px 배수.

## 2. 레이아웃

- Electron 창: 최소 폭 1240px 기준으로 디자인하고, 그 이상 폭에서는 여백 또는 사이드바 확장으로 대응한다.
- 좌측 GNB 232px 고정 폭 + 우측 콘텐츠는 유동 폭.
- 콘텐츠는 2열(주 + 사이드 320~360px) 또는 카드 그리드.

## 3. 공통 컴포넌트 — GNB

공유 컴포넌트로 구현. props: `active`(8개 메뉴 키), `live`(boolean).

- 상단 로고 → LIVE 배너(`live`일 때만, 콘솔로 이동) → 메뉴 8개 → 하단 플랫폼 연동 상태 + 계정.
- 메뉴: 대시보드 · 방송 콘솔 · 일정 · 세션 리포트 · 클립 · 성장 리포트 · 포트폴리오 · 비즈니스 매칭.
- 활성 항목만 Primary Soft 배경 + 인디고 텍스트/600, 나머지는 투명 + `#4a4f5a`/500.
- 아이콘은 24 viewBox 스트로크 1.8 라인 아이콘으로 통일.

## 5. 주요 설계 결정

1. **SC-01 3분할** — 인증(01a) / 연동(01b) / 가입(01c)을 분리. 연동 화면을 재사용해 토큰 만료 시 재연동 진입점으로 씀.
2. **Web 공개 뷰 이원화** — SC-10 포트폴리오와 SC-11 디렉터리 모두 브라우저 크롬을 씌운 비인증 뷰를 별도 구현. SC-11에서 클릭 → SC-10 공개 뷰로 이동.

## 6. 상태 표현 규칙

- LIVE: 레드 도트 + `box-shadow` 링, 배경 `#fef2f2` / 테두리 `#fecaca`.
- 연결됨: 그린 도트, 만료: 앰버 배너 + `연동 관리` CTA.
- 증가/감소: Success / Danger 텍스트 + 화살표, 수치는 mono.
- 진행 중(클립 생성 등): 뉴트럴 프로그레스 바 + 캡션.
